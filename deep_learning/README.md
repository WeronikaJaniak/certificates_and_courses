# Deep Learning Specialization

**Provider:** DeepLearning.AI  
**Instructor:** Andrew Ng  
**Platform:** Coursera  
**Status:** In Progress

The Deep Learning Specialization develops practical and theoretical skills
in neural networks, deep learning, optimization, computer vision,
sequence models, and modern deep learning architectures.

## Courses

### 1. Neural Networks and Deep Learning

**Topics:** Neural networks, forward and backward propagation, activation
functions, vectorization, shallow neural networks and deep neural networks.

[View Certificate →](Neural_Networks_and_Deep_Learning.pdf)

---

### 2. Improving Deep Neural Networks: Hyperparameter Tuning, Regularization and Optimization

**Topics:** Hyperparameter tuning, regularization, optimization algorithms,
batch normalization, initialization and gradient checking.

---

### 3. Structuring Machine Learning Projects

**Topics:** Machine learning strategy, error analysis, bias and variance,
transfer learning, multi-task learning and end-to-end deep learning.

---

### 4. Convolutional Neural Networks

**Topics:** Convolutional neural networks, computer vision, residual networks,
object detection, face recognition and neural style transfer.

---

### 5. Sequence Models

**Topics:** Recurrent neural networks, GRUs, LSTMs, word embeddings,
attention mechanisms and transformers.
