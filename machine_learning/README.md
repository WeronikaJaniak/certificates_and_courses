# Machine Learning

This directory contains certificates from the **Machine Learning Specialization**
offered by **DeepLearning.AI and Stanford Online** through Coursera.

The specialization covers the foundations of modern machine learning, including
supervised learning, neural networks, decision trees, clustering, recommender
systems, and reinforcement learning.

## Machine Learning Specialization

**Provider:** DeepLearning.AI & Stanford Online  
**Instructor:** Andrew Ng  
**Platform:** Coursera  
**Status:** Completed
